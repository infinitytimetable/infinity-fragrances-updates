# Infinity Fragrances Hub: app updates

The Infinity Fragrances phone and PC apps download new versions from here by themselves.

- `version.json` names the newest version and its files.
- `android-*.html` and `desktop-*.html` are the app screens for each version.

Every file is digitally signed. The apps check the signature with a key built into them and refuse anything that was not signed by Infinity Fragrances. No business records are kept here.
